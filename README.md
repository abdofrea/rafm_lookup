
# RAFM Lookup Process Simulation with different Data representation

This repository contains various data representations for the lookup process and compares their outcomes in terms of size and performance time within the context of RAFM
- SQlite3.
- Python Set.
- Python List.
- Bloom Filter.
  

This is part of the article ([RAFM Lookup process and (Bloom Filter)](https://www.linkedin.com/pulse/rafm-lookup-process-using-different-data-abdalwahed-freaa-9gpsf/)).
